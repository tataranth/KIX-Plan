# Kyoto Trip Handbook

เว็บคู่มือทริปเกียวโต อูจิ นารา และโอซาก้า 1–6 ธันวาคม 2026 สำหรับเปิดบนมือถือระหว่างเดินทาง
เป็นเว็บ static ไม่มี build step เผยแพร่ด้วย GitHub Pages จาก branch `main`

## ไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | โครงหน้า |
| `data.js` | ข้อมูลทริปทั้งหมด: แผนรายวัน งบ ร้านอาหาร เช็กลิสต์ |
| `app.js` | แสดงผลและการโต้ตอบ |
| `style.css` | หน้าตา ธีมสว่างและมืด |
| `sw.js`, `manifest.json`, `icon*` | โหมดออฟไลน์ และการเพิ่มไปยังหน้าจอโฮม |
| `Plan_A_Kyoto_1-6Dec_2026.md` | แผนต้นฉบับ |
| `AGENTS.md` | แนวทางการแก้ไขโปรเจกต์ |

## เปิดดูในเครื่อง

```
python -m http.server 8765 --bind 127.0.0.1
```

แล้วเปิด <http://127.0.0.1:8765/> (เปิด `index.html` ตรง ๆ ก็ได้ แต่โหมดออฟไลน์จะไม่ทำงาน)

## ใช้แบบออฟไลน์

1. เปิดเว็บหนึ่งครั้งขณะมีเน็ต บนเครื่องที่จะใช้เดินทาง
2. เพิ่มไปยังหน้าจอโฮม (ไม่บังคับ แต่ช่วยให้ข้อมูลที่เก็บไว้อยู่นานขึ้นบน iPhone)
3. หลังแก้แผนทุกครั้ง เปิดเว็บอีกครั้งขณะมีเน็ตเพื่อรับเวอร์ชันล่าสุด

ภาพแผนที่และลิงก์ Google Maps ยังต้องใช้เน็ต ส่วนแผนรายวัน งบ และข้อมูลทริปอ่านได้ครบ
